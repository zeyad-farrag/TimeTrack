## Approach (this repo)

1. **Initialize Go module + pin backend libraries** — `go mod init github.com/multica-ai/team-app` (Task 1.2 mandates this exact path; see Assumption 2). Run `go get` for each of: `github.com/go-chi/chi/v5`, `github.com/jackc/pgx/v5`, `github.com/sqlc-dev/sqlc/cmd/sqlc`, `github.com/teambition/rrule-go`, `github.com/gorilla/websocket`, `github.com/google/uuid`, `github.com/prometheus/client_golang/prometheus`. `go mod tidy`. Commit `go.mod` + `go.sum`. (AC1)
2. **Scaffold Go directory tree with placeholder packages** — create every directory enumerated in the Files-to-touch table under `internal/`, `pkg/db/`, `migrations/`, `scripts/team-app-cli/`. Each Go subpackage gets a one-line `doc.go` (`// Package <name> ...`). The four sole-writer packages (`internal/multica`, `internal/service/approval`, `internal/service/autofill`, `internal/handler/workspace_work_week.go`) include the AR14 `// SOLE WRITER:` comment per Dev Notes Architectural Rule 2. (AC3, AR14)
3. **Implement env-var validation in `internal/boot/boot.go`** — function `ValidateRequiredEnv() error` that checks each of the ten vars (`DEFAULT_ORG_SLUG`, `DEFAULT_ORG_NAME`, `ORG_CREATION_ENABLED`, `TEAM_APP_SHARED_SECRET`, `TEAM_APP_URL`, `MULTICA_BASE_URL`, `MULTICA_WS_URL`, `TEAM_APP_SYSTEM_USER_PAT`, `TEAM_APP_SYSTEM_USER_ID`, `DATABASE_URL`). For empty values, return an error naming the missing var. For `ORG_CREATION_ENABLED`, parse case-insensitive `true`/`false`; reject empty/unparseable with the same error path. **No defaults, no fallbacks.** (AC5, Task 5)
4. **Write `cmd/server/main.go`** — call `boot.ValidateRequiredEnv()`; on error, `slog.Error("missing required env var", "missing_env_var", name)` and `os.Exit(1)`. Set up `slog` JSON handler with the required structured-fields contract (`org_id`, `workspace_id`, `actor_user_id`, `outcome`, `duration_ms` — emit empty defaults). Connect via `pgxpool.New(ctx, os.Getenv("DATABASE_URL"))`. Mount the chi router from `router.go` with an explicitly configured `http.Server` on `:8080`. Add a `// TIME-RULE:` comment near any time use (Architecture Enforcement Guideline #9 — no `clock.Clock` interface; inject `time.Now` via struct field for tests). (AC3, AC5)
5. **Write `cmd/server/router.go`** — function returning `chi.Router` with `GET /healthz` (200 OK + tiny JSON body), and an `/api/v1` group placeholder. Add a comment naming AR13 (handlers thin → service → `*db.Queries`; handlers must NOT call `pkg/db/queries/*.sql` directly). (AC3, AR13)
6. **Add `internal/boot/boot_test.go`** — table test using `t.Setenv` to set all ten vars then unset one at a time, asserting each missing var produces an error mentioning that var's name. (AC5, Task 5.4)
7. **Add `sqlc.yaml`** mirroring `server/sqlc.yaml` from the multica monorepo: `version: 2`, `sql.engine: postgresql`, `sql.queries: pkg/db/queries/`, `sql.schema: migrations/`, `sql.gen.go.out: pkg/db/generated`, `sql.gen.go.sql_package: pgx/v5`, `emit_json_tags: true`, `emit_empty_slices: true`. (AC3, Task 2.4)
8. **Scaffold the Next.js frontend** — from the repo root, run `pnpm create next-app frontend --ts --app --tailwind --eslint --no-src-dir --import-alias "@/*"` (exact flags — non-negotiable per AC2). Then `cd frontend && pnpm add @tanstack/react-query @base-ui/react zustand date-fns`. Configure semantic Tailwind tokens in `tailwind.config.ts` and `app/globals.css` (no hardcoded hex; pattern borrowed conceptually from multica `packages/ui/styles/` but **not** imported). Leave `frontend/app/page.tsx` as the create-next-app default — auth wiring is Story 1.5. (AC2, Task 3)
9. **Create `frontend/packages/core/team/index.ts` and `frontend/packages/views/team/index.ts`** — placeholder export plus a banner comment documenting AR22 (no `next/*`, no `react-router-dom`, no UI libs in `core/team/**`; no `next/*` in `views/team/**`). Also a comment in `core/team/index.ts` noting TanStack Query owns server state and Zustand owns client state — frozen reference for downstream work. (AC3, AC6, Task 3.4)
10. **Add `frontend/.eslintrc.cjs` (or extend the generated ESLint config — see Assumption 11)** — `no-restricted-imports` rules:
    - `packages/core/team/**`: forbid `next/*`, `react-router-dom`, `react-dom`, `react-dom/*`, `@base-ui/react`, `tailwindcss/*`. Use `no-restricted-globals` for `process` and `localStorage` / `window` references.
    - `packages/views/team/**`: forbid `next/*`, `react-router-dom`. Forbid imports from `core/team/store` (stores live there but views consume via core's public surface).
    - `app/**`: unrestricted (the only place that may import `next/navigation`, `next/headers`).
    Verify by running `pnpm --filter frontend lint` after sample violations. (AC6)
11. **Write `Dockerfile`** — multi-stage: `FROM golang:1.26.2-alpine AS builder` (`go build -o /team-app-server ./cmd/server`); pinned `FROM gcr.io/distroless/static:nonroot` (copy `/team-app-server`, run as nonroot, set `ENTRYPOINT ["/team-app-server"]`). (AC4)

(AC4, AR4)
14. **Write `nginx/team.conf`** — `listen 80;` (production `:443` with Let's Encrypt commented as `# TODO: production cert` per AR7). `server_name team.multica.uittai.com;`. Locations (order-sensitive): `location /api/` → `proxy_pass http://api:8080;`; `location /gates/` → `proxy_pass http://api:8080;`; `location /` → `proxy_pass http://frontend:3000;`. Pass `Host`, `X-Forwarded-For`, `X-Forwarded-Proto`. For `location /api/v1/orgs/{orgID}/events` set `proxy_buffering off;` and `proxy_read_timeout 1h;` (SSE long-lived). (AC4, Task 4.4)
15. **Write `.env.example`** — every variable from AR8 with example values; `DATABASE_URL=postgresql://postgres:postgres@db:5432/team_app?sslmode=disable`. Add `frontend/.env.local.example` with frontend-side vars. Add `.gitignore` excluding `.env`, `frontend/.next/`, `frontend/node_modules/`. (AC4, AC5)
16. **Add `.github/workflows/ci.yml`** with three jobs:
    - `backend`: Go 1.26.1, `pgvector/pgvector:pg17` service container on `:5432`, `go test ./...`.
    - `frontend`: Node 22, `pnpm install`, `pnpm lint` (boundary check), `pnpm build`.
    - `migrate-test` placeholder job: a no-op step or `echo "Story 1.6 lands the migration runner"` (Task 7.2). (AR9)

## Test strategy (this repo)

- **Unit (Go).** `internal/boot/boot_test.go` is the only meaningful test in this story. Drive `ValidateRequiredEnv` with `t.Setenv` — for each of the nine vars, set the other eight, unset the target, assert the returned error names the missing var. Add a separate sub-test for `ORG_CREATION_ENABLED` set to an unparseable value (e.g. `"yes"`) — assert error path. Standard `testing` package; no third-party assertion library. (AC5, Task 5.4)
- **Lint (frontend).** `pnpm --filter frontend lint` runs in CI and MUST flag any boundary violation. Sanity-check during dev: temporarily add `import { useRouter } from "next/router"` to a file under `frontend/packages/core/team/` and verify lint fails; remove before commit. (AC6, Task 6.2)
- **CI smoke.** The `backend` job runs `go test ./...`; the `frontend` job runs `pnpm install && pnpm lint && pnpm build`. Both must pass on the issue branch.
- **Manual verification.**
  1. `docker compose up` boots `db`, `api`, `frontend`. `curl http://localhost:8080/healthz` returns 200. (AC4)
  2. With nginx fronting (locally via the compose file's `nginx` container if added, OR documented as deferred — see Assumption 9), `curl -H "Host: team.multica.uittai.com" http://localhost/api/healthz` proxies to `api:8080` and returns 200; `curl -H "Host: team.multica.uittai.com" http://localhost/` proxies to `frontend:3000`. (AC4)
  3. Running `./team-app-server` (or `go run ./cmd/server`) without `DEFAULT_ORG_SLUG` exits non-zero with a clear error naming the variable. (AC5)

No coverage targets in this story (per "Coverage target: none in this story" in the story's Testing standards).
